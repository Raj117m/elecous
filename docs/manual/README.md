## What ELECOUS is (verified: `elecous/bootstrap.py`, `elecous/governance/constitution.py`)

ELECOUS is a scientific demand-intelligence platform. It ingests real public
observations, discovers environmental factors that precede demand spikes,
forms causal *mechanisms*, validates them against history and against the
future, and emits ranked *opportunities* (predicted demand increases) with
evidence. A governing constitution (`elecous/governance/constitution.py`)
forbids synthetic observations: every stored observation must trace to a real
public source with provenance.

## Measured state (session 2026-07-06, via live API `/api/activity`, `/api/health/system`)

- **1,702,818** real observations spanning 2015–2026
- **2,382** demand episodes across every year 2017–2026
- **147** validated mechanisms (of ~680 total; 467 retired, rest candidate)
- **64** predictions generated; prospective outcomes pending their windows
- Rolling benchmark: ELECOUS F1 **0.631** vs single-signal baseline **0.626**
- Storage ~5.6 GB; 11 sources; 107/107 non-network tests passing

## How to extend or complete this manual

Each skeleton names the exact files to read. The reliable inspection commands
(no database lock, no network):

```bash
find elecous -name "*.py" -not -path "*__pycache__*"     # 196 modules
grep -rln "Migration(" elecous --include="*.py"           # schema owners
grep -rn "scheduler.register" elecous/scheduler/registration.py  # scheduled tasks
grep -rn "@router" elecous/dashboard/api/routes.py        # API endpoints
```

Do not query the databases while `elecous run` or the dashboard is live —
DuckDB is single-writer and will lock (observed repeatedly this session). Read
through the running instance's HTTP API instead, or stop the process first.
